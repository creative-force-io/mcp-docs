# Support and contact

## Get help with setup or usage

- **Documentation:** start with the [setup guide](setup.md), the
  [tool reference](tool-reference.md), and the [use-case guide](use-cases.md).
- **Existing Creative Force customers:** reach out through your usual Creative Force support
  channel or account manager.
- **Everyone else:** open an issue at
  <https://github.com/creative-force-io/mcp-docs/issues>, or contact Creative Force via
  <https://creativeforce.io>.

## Report a problem with the MCP integration

If a tool returns an error, missing data, or unexpected results, please include:

- the tool name (e.g. `query_ecomm_production`),
- the prompt or parameters you used,
- what you expected versus what you got,
- the approximate time and your workspace name.

You can also send feedback directly from any connected client — just ask the assistant to
*"send feedback to Creative Force"*, which uses the `send_feedback` tool.

## Marketplace / listing review

For questions about the Anthropic Claude integrations directory or the Model Context Protocol
registry listing, open an issue at
<https://github.com/creative-force-io/mcp-docs/issues> or contact Creative Force via
<https://creativeforce.io>.

## Security

To report a security or privacy concern, see **[SECURITY.md](SECURITY.md)**. Please do not open a
public issue for security reports.

## Privacy

What the server accesses and does not store is documented in **[privacy.md](privacy.md)**.
